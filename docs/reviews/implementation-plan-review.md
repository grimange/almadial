## External documentation check and limits

Official documentation was consulted during repository discovery on 2026-11-05. These are documentation observations, not installation tests. Mutable web pages and branch names must be replaced by exact source/package identities in M0.

- AlmaLinux's [10.0 release notes](https://wiki.almalinux.org/release-notes/10.0) list PHP 8.3, Perl 5.40, MariaDB 10.11 and Apache 2.4, and distinguish default v3 from the v2 image. Its [10.2 notes](https://wiki.almalinux.org/release-notes/10.2) list additional PHP 8.4/MariaDB 11.8 packages. Availability does not choose the tested runtime.
- The [Asterisk lifecycle table](https://docs.asterisk.org/About-the-Project/Asterisk-Versions/) lists 22 LTS with October 2029 EOL. Its displayed 24 status and release dates are not fully aligned; recheck before selecting any alternative. No switch away from the 22 candidate is proposed.
- Official [chan_sip guidance](https://docs.asterisk.org/Configuration/Channel-Drivers/SIP/Configuring-chan_sip/) confirms removal in 21. The [module-deprecation table](https://docs.asterisk.org/Development/Asterisk-Module-Deprecations/) also flags removed Macro/Monitor paths and describes MeetMe's removal as paused. Inspect the exact selected tree and modules; do not assume a generic removal or compatibility verdict.
- The [WebRTC guide](https://docs.asterisk.org/Configuration/WebRTC/Configuring-Asterisk-for-WebRTC-Clients/) documents PJSIP, WebSocket modules and trusted certificates. The [ConfBridge guide](https://docs.asterisk.org/Configuration/Applications/Conferencing-Applications/ConfBridge/ConfBridge-Configuration/) describes profiles and menus. Neither proves VICIdial's allocation and call semantics or the proposed Apache proxy.
- VICIphone's [v3.0 README](https://raw.githubusercontent.com/vicimikec/ViciPhone/v3.0/README.md) identifies SIP.js 0.20.1, rtcp_mux and settings-container integration requirements; its [branch license](https://raw.githubusercontent.com/vicimikec/ViciPhone/v3.0/LICENSE) is AGPLv3. The [VICIdial legal page](https://www.vicidial.com/legal/) describes current licensing as AGPLv2. Exact revision licenses and delivery obligations still require artifact-level review.
